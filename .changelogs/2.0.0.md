

**Important:**<br>
If you had any custom configs from versions 1.2.4 or earlier (or from the original Better Foliage mod) you will have to replicate them manually.

As of version 2.0.0 much of the mod's configurations have changed. The old config file in the located at `config/BetterFoliage.cfg` is no longer used, and instead the mod now uses a new file located at `config/BetterFoliage_LegacyEdition.cfg`.

Your old file will not be deleted, but not all configs are compatible with the new file. You can use it as a reference when replicating your custom configs or delete it.

This should be the last time a config change is ever required, as the mod now keeps its own up-to-date configs in a resourcepack, separate from the player's custom configs.

---

In this version, the mod has been completely rewritten from Kotlin to Java and every feature has been reimplemented, most with additional configuration options. The complete list would be too long for a changelog, but you can check out all of them in the [Features](https://github.com/Kynake/BetterFoliage/wiki/Features) wiki page.

Due to the language change the mod also no longer depends on [Forgelin: Legacy](https://github.com/LegacyModdingMC/Forgelin) or [GTNH's Forgelin](https://github.com/GTNewHorizons/Forgelin/releases).

Requires [UniMixins](https://github.com/LegacyModdingMC/UniMixins/releases)

---

## Additions

- The whitelists/blacklists of blocks has been reworked into lists of Block Filters, which offer more in-depth options on which blocks should and should not be considered valid for each of the mod's features. For more information check the [Block Filters](https://github.com/Kynake/BetterFoliage/wiki/Block-Filters) wiki page.

- The lists of biomes per feature has been reworked into lists of Biome Filters, which allow the valid biomes for a specific feature to be preconfigured without relying on the biome's ID, which may be different for different modpacks. For more information check the [Biome Filters](https://github.com/Kynake/BetterFoliage/wiki/Biome-Filters) wiki page.

- Additional block and biome filters may be added by other mods or resource packs without overriding the player's config file. These filters will 'stack' with each other in the order they are loaded. This allows resource packs to override filters from other mods / resource packs without altering other unrelated filters. For more information check out the [Resource Pack Integration](https://github.com/Kynake/BetterFoliage/wiki/Resource-Pack-Integration) wiki page.

- A new in-game command has been added to help with getting block or biome information for filters.<br>
 Type `/betterfoliage block` to get information about the block you're currently looking at or `/betterfoliage biome` for information about the biome you're currently in.

- The mod now uses a fixed seed for its features, and no longer depends on the world seed. This means a world in MP will look the identical to the same world in SP. This seed can be changed in the mod's settings.

- Soul Sand blocks can now be specified as a Block Filter. This allows Soul Particles to appear from more blocks. Compatibility for EFR's Soul Soil has been added by default.

- Added a config option to toggle Biomes O' Plenty to render rounded leaves, defaulting to true. \[[#31](https://github.com/Kynake/BetterFoliage/issues/31)]

## Fixes
- Fixed a bug where most features would render in pitch black when using shaders and Angelica 2.0.0-alpha9 or later. \[[#28](https://github.com/Kynake/BetterFoliage/issues/28)]
- Improved side selection for extra leaves ambient occlusion, which should also fix a bug where leaves would sometimes render in pitch black. \[[#4](https://github.com/Kynake/BetterFoliage/issues/4), [#33](https://github.com/Kynake/BetterFoliage/issues/33)]
- Fixed some lighting bugs where Angelica would consider Round Logs as full blocks.
- Fixed some invisible face bugs with modded liquids.
- Fixed some invisible face bugs when blocks were placed next to Round logs or opaque leaves.
- Fixed some invisible face bugs with GregTech 6.
- Fixed some bugs when rendering Round Logs from IndustrialCraft 2.
- Fixed some bugs when rendering Round Logs from TerraFirmaCraft.

## Improvements
- Rendered features have been improved and given more config options. See [Features](https://github.com/Kynake/BetterFoliage/wiki/Features) wiki page for more info.
- The config file and in-game menu has been improved. The config file should now also use Minecraft's current language when configs are altered in-game.
- Ambient occlusion shading has been improved for Extra Leaves, Round Logs and Better Cactus.
- Connected Grass and Round Logs no longer render faces that can be determined to be hidden by other blocks.
- Round Logs require less render calls in general, especially when multiple logs are place along the same axis.
- The alpha mask for Extra Leaves in fast / opaque blocks has been improved.
- The color of modded Leaf Particles in GT5U polluted chunks has been improved.

## Removed Support
- Support for normal maps and specular textures when generating extra leaf or short grass textures has not been reimplemented yet, and will be done so later.
